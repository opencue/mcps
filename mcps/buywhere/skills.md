# buywhere skills

Agent-native product catalog API for Southeast Asia commerce.

MCP source: [https://www.npmjs.com/package/@buywhere/mcp-server](https://www.npmjs.com/package/@buywhere/mcp-server)

Package: `@buywhere/mcp-server`

Install: `npx -y @buywhere/mcp-server`

Expected type: `stdio`

API key: required. Set `BUYWHERE_API_KEY`.

## Coverage

Searches 1.5M+ products across Shopee, Lazada, Amazon SG, and 50+ merchants.
Multi-currency support: SGD, USD, MYR, IDR, THB, PHP, VND.

## Tools

| Tool | Purpose |
| --- | --- |
| `search_products` | Full-text product search across all indexed merchants. |
| `get_product` | Fetch detailed product info by ID. |
| `compare_prices` | Compare prices for an item across multiple merchants. |
| `get_deals` | Discover current deals, flash sales, and discounts. |
| `browse_categories` | List product categories available for browsing. |
| `get_category_products` | Get products for a specific category. |
